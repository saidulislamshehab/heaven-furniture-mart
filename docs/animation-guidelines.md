# Heaven Furniture Mart — Animation Guidelines

## Animation Philosophy

Animations should feel:

- Smooth
- Slow
- Elegant
- Intentional
- Premium

Avoid:

- Bouncy animations
- Fast spinning effects
- Excessive parallax
- Random motion
- Over-animation

---

# Recommended Animations

## Hero

- Slow image scale
- Gentle fade-in
- Text reveal
- Subtle content transition

---

## Scroll Animations

Use:

- Fade up
- Fade in
- Mask reveals
- Image reveal
- Text stagger

Keep durations smooth.

Recommended range:

0.5s–1.2s

---

# Image Effects

Possible:

- Slow zoom
- Clip-path reveal
- Image mask reveal
- Subtle hover movement

---

# Hover Effects

Cards and images can use:

- Slight scale
- Image zoom
- Text reveal
- Border transition

Avoid aggressive movement.

---

# Performance Rule

Animations must not reduce:

- Mobile performance
- Page speed
- Interaction responsiveness

Use transforms and opacity whenever possible.

Respect prefers-reduced-motion.
