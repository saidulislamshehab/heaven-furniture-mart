# Heaven Furniture Mart — Implementation Plan

## Important Development Strategy

Do NOT build the entire landing page in one prompt.

Build the project incrementally.

Each phase should be:

1. Implemented
2. Reviewed
3. Improved
4. Tested

Only then move to the next phase.

---

# Phase 1 — Project Foundation

Tasks:

- Inspect existing project structure
- Understand framework and dependencies
- Configure fonts
- Configure global colors
- Create design tokens
- Set up reusable layout utilities
- Prepare asset structure

Do not build the entire page yet.

---

# Phase 2 — Global Components

Build:

- Navbar
- Container system
- Buttons
- Section heading
- Footer foundation

Focus on consistency.

---

# Phase 3 — Hero Section

Build only the hero.

Requirements:

- Cinematic
- Premium
- Strong typography
- High-quality imagery
- Clear CTA
- Excellent mobile experience

Review and polish before moving on.

---

# Phase 4 — Brand Story

Build:

- Brand introduction
- Editorial layout
- Typography hierarchy
- Image composition

Focus on storytelling.

---

# Phase 5 — Collections

Build:

- Collection showcase
- Large editorial images
- Minimal category information

Do not build ecommerce functionality.

---

# Phase 6 — Bespoke Experience

Build:

- Bespoke section
- Customization story
- Design process
- Process animation

This is one of the highest priority sections.

---

# Phase 7 — Trust & Craftsmanship

Build:

- Why Choose Heaven
- Trust points
- Craftsmanship visuals
- Material details

---

# Phase 8 — Social Proof

Build:

- Managing Director quote
- Brand credibility
- Milestones

---

# Phase 9 — Final Conversion

Build:

- Strong final CTA
- Contact information
- Footer

Ensure the primary action is obvious.

---

# Phase 10 — Motion & Interactions

Add:

- Scroll reveals
- Image animations
- Hover effects
- Text transitions

Do not add unnecessary effects.

---

# Phase 11 — Responsive Optimization

Test:

- Mobile
- Tablet
- Desktop

Fix:

- Typography
- Layout
- Spacing
- Images
- Navigation

---

# Phase 12 — Performance Optimization

Optimize:

- Images
- Lazy loading
- JavaScript
- Animation performance

---

# Phase 13 — Final Hackathon Polish

Review:

- Visual consistency
- CTA clarity
- Loading speed
- Mobile experience
- Animation quality
- Typography
- Image quality

Remove anything that feels generic or unnecessary.
