# Heaven Furniture Mart — Responsive Guidelines

## Priority

Mobile is not a secondary version.

The landing page must feel intentionally designed for:

- Desktop
- Tablet
- Mobile

---

# Mobile Principles

On mobile:

- Reduce unnecessary visual complexity
- Maintain strong typography
- Preserve image quality
- Keep CTA visible
- Avoid excessive animation
- Maintain comfortable spacing

---

# Navigation

Desktop:

Full navigation.

Mobile:

Minimal menu.

Primary CTA should remain easy to access.

---

# Hero

Desktop:

Large cinematic layout.

Mobile:

Prioritize:

- Headline
- Image
- CTA

Do not allow the hero to become excessively tall.

---

# Typography

Typography should scale smoothly.

Do not simply shrink desktop typography.

Maintain strong hierarchy.

---

# Images

Use responsive image sizes.

Avoid downloading huge desktop images for mobile.

---

# Touch Interaction

Buttons should have comfortable touch targets.

Recommended minimum:

44px height.

---

# Testing

Test at minimum:

Mobile:

375px
390px
430px

Tablet:

768px

Desktop:

1920px
