# Heaven Furniture Mart — Visual Direction

## Core Inspiration

The website should feel like:

A luxury interior design studio

- An architecture portfolio
- A premium editorial magazine

Not:

A furniture ecommerce marketplace.

---

# Photography Direction

Prioritize:

- Real Heaven Furniture Mart photos
- Showroom photography
- Furniture close-ups
- Material textures
- Lifestyle interiors
- Craftsmanship details

Images should feel:

- Warm
- Natural
- Premium
- Cinematic
- Editorial

---

# Image Composition

Use:

- Full-width photography
- Large image blocks
- Cropped close-ups
- Asymmetrical layouts
- Vertical editorial images
- Layered compositions

Avoid:

- Small repetitive thumbnails
- Generic stock images
- Product images with white backgrounds everywhere

---

# Visual Hierarchy

The most important elements should be:

1. Photography
2. Typography
3. Whitespace
4. CTA
5. Supporting information

---

# Layout Style

Prefer:

- Asymmetrical grids
- Split layouts
- Large typography
- Overlapping elements
- Editorial compositions

Avoid:

- Repetitive 3-column sections
- Generic SaaS layouts
- Too many feature cards

---

# Luxury Details

Use subtle:

- Brass lines
- Fine borders
- Architectural spacing
- Material textures
- Typography contrast

Luxury should come from:

- Composition
- Whitespace
- Typography
- Photography

Not from excessive visual effects.

---

# Important Rule

Every section should feel intentionally art-directed.

The landing page should not look like it was generated from a generic component library.
