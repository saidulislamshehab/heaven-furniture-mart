# Heaven Furniture Mart — Performance Guidelines

## Performance Philosophy

Visual quality should never make the website slow.

Luxury does not mean heavy.

The website should feel:

- Fast
- Smooth
- Responsive

---

# Images

Always:

- Compress images
- Use modern formats when possible
- Use responsive image sizes
- Lazy load below-the-fold images

Prioritize loading the hero image.

---

# JavaScript

Avoid unnecessary:

- Heavy libraries
- Large animation packages
- Unused dependencies

---

# Animation

Use:

- CSS transforms
- Opacity transitions

Avoid layout-heavy animations.

---

# Loading Strategy

Prioritize:

1. Navigation
2. Hero content
3. Hero image
4. Above-the-fold content

Lazy load:

- Gallery images
- Lower page sections
- Non-critical media

---

# Final Goal

The website should feel visually rich without feeling heavy.
